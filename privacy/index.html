개인정보처리방침

시행일 2026년 7월 28일 · 고지 버전 2026-07-28 · 미브 (Meve)

미브 (Meve, 대표 김시우, 이하 “미브”)는 이용자가 자신의 피부·건강 데이터 사용 범위를 직접 정할 수 있도록 개인정보보호법과 Apple 플랫폼 정책에 따라 이 방침을 공개합니다. MEVE 앱과 meve.beauty 웹사이트에 적용됩니다.

i.처리하는 정보와 수집 방법

서비스 제공에 필요한 최소한의 정보만 처리합니다. 피부·건강정보와 외부 자동화 분석은 별도 화면에서 각각 선택을 받아요.

구분처리 항목수집 방법
계정·운영 이메일, 로그인 제공자 식별자, 닉네임, 프로필 사진, 티켓 번호, 가입·동의 일시, 앱 버전·OS·기기 종류, 푸시 토큰, 접속·오류·보안 기록 가입·로그인, 직접 입력, 서비스 이용
민감정보 피부 사진·관찰값·타입·고민, 제품 반응, 주의 성분, 트러블·체크인·루틴, 생리주기·증상, 선택해 연결한 Apple 건강 하루 합계 별도 동의 후 카메라·직접 입력·Apple 건강 읽기 권한
분석 입력 코치 질문, 메모, D-day 목표, 제품·성분표 사진과 이용자가 분석을 위해 직접 입력한 내용 외부 자동화 분석·국외 이전 동의 후 이용자의 기능 요청
공개·공유 이브 피드 게시물·댓글·공개 프로필, 이용자가 직접 만든 화장대 공유 링크의 제품 정보 직접 게시·공유
구독 Apple이 제공하는 상품·거래·구독 상태, RevenueCat 앱 사용자 식별자 App Store 결제·복원
웹 신청 출시 알림·베타·파트너십 신청에 직접 입력한 이메일, 이름·닉네임, 기기·신청 답변, 연락처·SNS·제안 내용(선택), 추천 코드·유입 경로 각 웹 폼 제출

비밀번호 인증 정보는 Supabase Auth가 처리하며 미브는 평문 비밀번호를 열람하지 않습니다. 연락처 전체, 정확한 GPS 위치, 광고 식별자는 수집하지 않습니다.

ii.처리 목적

  • 가입·로그인·티켓 확인·부정 이용 방지와 고객 지원
  • 피부 변화 기록, 제품·성분 확인, 루틴·D-day 참고안, 코치 답변 등 요청한 개인화 기능
  • 구독 권한 확인, 결제 복원, 사용량 제한과 비용 안전장치 운영
  • 별도 선택 동의가 있는 경우 기능별 성공·실패와 이용량을 집계해 품질 개선
  • 별도 마케팅 동의가 있는 경우 이벤트·체험단 소식 발송
  • 출시 알림·베타·파트너십 신청 확인, TestFlight 초대, 문의 회신과 친구 초대 순번 반영

피부 사진, Apple 건강, 생리주기 데이터는 광고·마케팅·행동 타기팅·데이터 판매에 사용하지 않습니다.

iii.보유 및 이용 기간

  • 계정·프로필·피부/제품/루틴 기록 · 회원 탈퇴 또는 이용자가 직접 삭제할 때까지
  • 얼굴 스캔 원본 · 미브 DB에 저장하지 않고 요청 처리 후 즉시 폐기. 외부 자동화 처리 입력·출력은 악용 방지 목적으로 일반적으로 최대 30일 보관될 수 있음
  • 비교용 정면 사진 · 이용자가 고른 0일·7일·30일 동안 해당 기기에만 보관
  • Apple 건강 하루 합계 · 연결 해제 시 삭제 여부를 선택할 수 있고 탈퇴 시 삭제
  • 선택 통계 · 철회 후 새 이벤트를 수집하지 않고 삭제 요청 또는 탈퇴 시 계정 연결 이벤트 삭제
  • 베타 테스터 신청 · 베타 테스트 종료 후 3개월 이내 파기, 이용자가 삭제를 요청하면 즉시 파기
  • 출시 알림 신청 · 수집 목적 달성(출시 안내 완료) 시 또는 이용자의 삭제 요청 시 지체 없이 파기
  • 파트너십 신청 · 검토 및 회신 완료 후 1년 보관 뒤 파기, 이용자가 삭제를 요청하면 즉시 파기
  • 법정 보관 · 계약·결제 5년, 소비자 불만·분쟁 3년, 표시·광고 6개월

목적·방법피부·성분·사용 기록의 자동화 분석 결과를 만들 때 암호화된 통신으로 전송

민감정보 처리, 외부 자동화 분석, 국외 이전을 각각 거부할 수 있습니다. 거부하면 사진 스캔·기록 기반 코치 등 외부 분석 기능은 사용할 수 없지만 계정 관리와 공개 콘텐츠는 이용할 수 있습니다.

vi.제3자 제공과 공개

미브는 개인정보를 판매하지 않으며 법적 근거 또는 별도 동의 없이 독립된 제3자에게 제공하지 않습니다. 다만 이용자가 이브 피드에 게시하거나 공유 링크를 만들면 선택한 정보가 다른 사람에게 공개됩니다. 공개 범위와 링크는 이용자가 관리할 수 있어요.

vii.이용자의 권리

이용자는 개인정보 열람·정정·삭제·처리정지와 민감정보·외부 자동화 분석·국외 이전·선택 통계·마케팅 동의 철회를 요청할 수 있습니다. 앱의 마이페이지 > 내 데이터 관리에서 동의 철회, 내보내기, 피부 분석 기록 삭제를 할 수 있고 마이페이지에서 회원 탈퇴할 수 있어요. Apple 건강 연결 해제와 시스템 권한 변경은 앱과 iPhone 설정에서 할 수 있습니다.

viii.자동화 분석 안내

  • 제품 DB·성분 규칙을 먼저 적용하고, 사진·문장 해석이 필요한 경우 외부 모델을 사용합니다
  • 피부 타입은 부위별 유분·건조·붉음 관찰값과 이용자 입력을 동일한 앱 기준으로 분류합니다
  • 조명·각도·화장·입력 누락·모델 오류로 결과가 달라질 수 있고 의료 진단·질환 판정·치료 지시가 아닙니다
  • 결과는 구매·결제·구독·회원 자격 또는 법적 권리·의무를 자동으로 결정하지 않습니다

결과를 무시하거나 수정 의견을 남기고 자동화 분석을 거부·철회할 수 있습니다. 구체적인 설명이나 사람의 검토는 아래 이메일로 요청할 수 있어요.

ix.접근 권한·쿠키·안전조치

카메라(피부·제품·성분표 촬영), 사진(직접 고른 사진 첨부·저장), Apple 건강 읽기(수면·걸음·운동 하루 합계), 알림은 모두 선택 권한이며 iPhone 설정에서 바꿀 수 있습니다. 위치 권한은 요청하지 않습니다.

광고·추적 쿠키와 제3자 광고 SDK를 사용하지 않습니다. 웹사이트의 대기 순번·초대 링크 등 기기 내 상태는 브라우저 저장소에 보관되며 브라우저 데이터 삭제로 지울 수 있습니다.

  • 만 14세 미만의 회원가입을 허용하지 않으며 확인 시 계정과 정보를 삭제
